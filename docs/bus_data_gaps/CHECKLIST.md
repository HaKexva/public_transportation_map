## F. 公車場站（調度站）座標

[`lib/geojson/bus_depots_manual.md`](../../lib/geojson/bus_depots_manual.md)（每縣市一張表）列出所有無法從站名推得場站的路線（2026-10 為 **3,608 列，全部未填**）。
TDX 沒有「路線所屬場站」資料，只能人工補。

- 每縣市先有「場站清單」（自動偵測的 `S…` 代碼，附地圖連結）；清單沒有的場站自己加一列（自訂代碼如 `N1`＋名稱＋經緯度）。
- 在「路線」表的「場站代碼」欄填代碼即可；手動指定會取代自動偵測。其餘欄位勿改。
- 只有地址時，經緯度留空、地址填備註，再跑 `bin/rails geojson:bus_depots_geocode`（需 Google Cloud 開帳單並啟用 Geocoding API）。
- 可依業者或縣市分批交；已填列會在 `bin/rails geojson:bus_depots_missing` 重產時保留。
